BatchDrop on AWS: a production design, September to October 2026

BatchDrop is a Rails platform for limited-time product drops and a lightweight SMS customer CRM, a nowtwo product; it ran on a single Hetzner box with Postgres and uploads on its disk and no monitoring.

On a phone this is easier to read full size.

This is the design I wrote and built to move it into the company's AWS organization. Three things to notice: the instance holds no state and can be rebuilt from cloud-init; nothing on the box or in state carries a long-lived credential; and the cutover is a DNS flag with the same flag as its rollback.

devbox

A Go CLI that gives each git worktree its own microsandbox VM on Apple Silicon, restored from a golden snapshot in seconds with the worktree bind-mounted so edits land live. The same VM shape runs Claude Code unattended with deny-by-default egress and, optionally, a repo-scoped GitHub token. devbox knows nothing about Rails or Go: what a golden contains, what runs after a restore, and what test means all come from the repo's own .devbox config or a recipe it names. Built for BatchDrop first, then made stack-agnostic so the agent below could use it for its build phase. Private repository.

An autonomous agent for my Obsidian vault

An always-on Mac reads task notes from my vault and does the work on a schedule: a research note becomes a research document, an idea note becomes a vertical slice on its own branch of a private repo with a PR open, and todos get triaged hourly. The governing rule is that data lives in the vault, policy lives where the agent cannot reach, and no agent process ever holds a credential. The agent's token is fine-grained and scoped to two repositories under my account; the runner itself lives under a separate organization that the agent reaches only through a read-only deploy key, so even a carelessly re-minted token cannot touch its own policy. Credentials sit in the macOS Keychain, and the vault's encrypted subtree is excluded by sparse checkout rather than merely left undecrypted. Private repository.

Three Ring Binder

A small clone of Pocket. Paste a link and the page is fetched, stripped down to its words and pictures, and kept on a shelf to read later. Accounts, search, offline reading, and EPUB export straight to a Kindle. Go, templ, TypeScript, sqlc, and Playwright end-to-end tests.
